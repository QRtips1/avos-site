# makesitefor.me

Showcase site of MakeSiteFor.me (Podgorica), served by GitHub Pages at https://makesitefor.me.

`index.html` is built from the source kept in the project files (`studio/site/vitrina.html`, `sh wrap.sh vitrina.html index.html`). Brand, contacts and the order form key are in the `CONFIG` block near the end of the file.
